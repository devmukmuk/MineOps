
# MineOps

Minecraft utility and automation toolkit written in Python.

## Features

* Server automation
* World backups
* RCON tools
* Player utilities
* Map exports
* Mod synchronization
* Interactive CLI

## Development

```bash
python -m venv .venv
source .venv/Scripts/activate
pip install -r requirements.txt
```

## Run

```bash
python -m mineops about
```

## Test

```bash
pytest
```
